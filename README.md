# ФЕШН — барбершоп

Адаптивная страница на HTML, CSS и JavaScript. Node.js 24; внешних npm-зависимостей нет.

## Запуск

```sh
cd /workspace/site
npm run dev
```

Сервер слушает порт 3000 на всех интерфейсах. Другой порт: `PORT=3001 npm start`.
Проверка синтаксиса: `npm run check`.

## Перед публикацией сайта

Цены предварительные. Добавьте реальный адрес, часы работы и контакты.
Форма сохраняет черновик только в localStorage браузера, не отправляет данные и не подтверждает запись. Для настоящей записи необходимо подключить сервис или серверный обработчик.
Изображение интерьера создано для демонстрации дизайна; замените его фотографиями реального барбершопа. Шрифты загружаются из Google Fonts, при недоступности используются системные.
